# Contributing

Report radio, ETHOS and GasDeck versions, affected view, source units and reproduction steps.
Distinguish live hardware from Synthetic preview. Do not upload private model/radio files,
logs, addresses or generated state. Sanitized screenshots are welcome.

Keep the widget read-only. Preserve bounded polling/history/drawing, optional gates,
correct source units and persistence compatibility. Explain changed estimate/alarm behavior.
No private helpers, model state, bytecode or unlicensed art in PRs.
VoltDeck is separate; shared bug fixes may need a corresponding change there.
