## Installation and source

Install only scripts/GasDeck/main.lua in a full-screen zone. Select actual sources,
capacities and fuel method. Logging and Synthetic preview default Off.
Keep model cfg/dat state on upgrades. Do not distribute a PC/simulator main.luac;
ETHOS compiles the readable Lua on its target. Remove only stale generated bytecode.
Source and original prose remain open under MIT. A named release ZIP comes later.

## Hardware mapping

GasDeck reads ETHOS sources; it does not discover, drive or configure AES hardware.
Discover/configure sensors in ETHOS first.

| Data | GasDeck assignment |
| --- | --- |
| RX1/RX2 voltage | Each battery's Voltage source. |
| Individual mAh/percent | Its own Consumed mAh / Percent source. |
| Combined RX current/consumption | RX total current / RX total consumed. |
| RPM/temperatures | Independent RPM/Temp 1-4 slots. |
| Flowmeter rate | Flow source and correct units. |
| Cumulative fuel used | Fuel used source in Capacity - consumed mode. |
| Actual remaining ml/percent | Remaining source and matching method. |
| Ignition command/feedback | Ignition status; never inferred from RPM. |
| RSSI/VFR | Actual dashboard and optional distinct log sources. |

AES II has four RPM inputs, seven temperature inputs and a flowmeter port; GasDeck
displays up to four chosen temperatures. Consult the manufacturer for wiring, sensor
compatibility, pulses, safe limits and IDs.
[FrSky AES II manual](https://www.flyingtech.co.uk/wp-content/uploads/2024/05/Advanced-Engine-Suite-II-Manual.pdf),
[FrSky North America AES II](https://frskyna.com/products/frsky-advanced-engine-suite).

TD SR18's two 2.4 GHz antennas and one 900 MHz antenna do not establish three telemetry
values; some firmware combines VFR.
[FrSky TD SR18 manual](https://www.flyingtech.co.uk/wp-content/uploads/2023/10/TD-SR18-Manual.pdf),
[FrSky TD R18](https://www.frsky-rc.com/td-r18/).
[ETHOS telemetry documentation](https://ethos-doc.frsky-rc.com/model-setup/telemetry/)
explains discovery and calculated sources. Manuals are linked, not bundled.

## Estimates and safety

Prefer individual consumed mAh or measured percent. Voltage estimates are marked EST;
LiFe's flat curve makes voltage capacity uncertain. LiPo 4.20-3.30 / LiFe 3.65-2.80
V/cell are display bounds, not recommended discharge or alarm settings.
Fuel estimates require correct baseline, calibration and continuous valid data.
Missing integrated flow cannot be reconstructed. Unknown is not full.
A command is not ignition-power feedback. GasDeck never controls ignition, throttle,
receiver power, safety switches or failsafe. Keep native alerts and physical safeguards.

## Images, fonts and resources

Reuse the model's selected image path; fitting preserves aspect ratio. At 800 x 480,
the image area is about 277 x 156 pixels. **320 x 180** is a good 16:9 illustration size
for this GasDeck panel; 290 x 191 also works with different unused margins.
An 800 x 480 model image is unnecessary. Limit: 160000 image pixels.
Use ETHOS-compatible RGB/RGBA 8-bit PNG, not palette/16-bit PNG.
Suite Image Manager is the safest conversion route.

ETHOS reported ExtraNG.png (320 x 180) as **115200 bytes / 112.5 KiB**.
Decoded dimensions, not PNG disk size, determine bitmap allocation.
Artwork in docs is optional, not a widget dependency. No font/audio/art is required.

Polling: at most 4 Hz. History: up to 180 points/channel, up to 48 minimum-preserving
render bins, gaps break traces. Graph preparation is spread across wakeups.
Earlier stress runs with 4 RPM, 4 temperatures and 3 RF slots showed about 1.66 MB
free Lua memory and 2506240 bytes free bitmap memory with repeated garbage collection,
not an obvious steadily growing leak. These are whole-environment free values.
Earlier PC measurements averaged 0.25-0.30 ms polling and 1-2 ms drawing; not radio CPU
percent or physical-radio guarantees. Check the actual model and other active widgets.

## Persistence and publication

Alternating checksum-protected gc*.cfg settings and gd*.dat counters are per model,
separate from VoltDeck. Sources remain in ETHOS. No file-per-flight logger.
Last qualified summary remains in RAM through aircraft shutdown and next qualification,
but not radio/widget restart. Finish flight / actual Refuel starts the next sortie with
receiver batteries retained.

Public: Lua, original docs, curated simulator screenshots, approved aircraft illustration.
Private: notes, tests/feeders, logs, cfg/dat state, model/radio bin files, bytecode,
manuals, sounds and fonts. Synthetic examples are not calibration evidence.
No GasDeck release is created during repository setup.
