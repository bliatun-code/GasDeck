# GasDeck example images

The menu and model-configuration images show GasDeck in the ETHOS 26.1.2 X20RS
simulator, using the Extra NG 78 example with Great Power / 38 cc, one engine and
a dark background. The layout examples use illustrative readings, peaks,
counters and histories.

The Home-menu image shows all five choices. Flight-log images include the
bottom-right Diagnostics button, also available in the empty-log example.
The final Flight session settings image shows Reset live peaks and Reset flight count.

Extra NG 78 / Great Power 38 cc is used with permission. Multi-engine and
multi-temperature variants are hypothetical, not its installed hardware.
The 320 x 180 aircraft PNG is optional documentation art; see [NOTICE](../../NOTICE.md).
