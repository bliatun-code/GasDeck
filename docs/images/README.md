# GasDeck example images

The menu and model-configuration images show GasDeck in the ETHOS 26.1.2 X20RS
simulator. The model-configuration image shows defaults: no engine brand, 60 cc,
one engine and Radio theme. The layout examples use Great Power / 38 cc with
illustrative readings, peaks, counters and histories.

Extra NG 78 / Great Power 38 cc is used with permission. Multi-engine and
multi-temperature variants are hypothetical, not its installed hardware.
The 320 x 180 aircraft PNG is optional documentation art; see [NOTICE](../../NOTICE.md).
